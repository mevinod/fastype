# Fastype

10fastfingers-style typing test clone with:
- 60-second typing game
- Daily top-20 leaderboard (rolling 24h)
- User tracking via cookie + IP fallback (24h return window)

## Run locally

```bash
npm install
npm start
```

Open: `http://localhost:4173/`
